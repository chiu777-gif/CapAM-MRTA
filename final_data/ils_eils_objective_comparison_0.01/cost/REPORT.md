# ILS / EILS 固定数据集测试

数据：`/home/hustcsib/chiu_code/CapAM-MRTA/z_test_path/data/n100_obstacles_example.pkl`，共 100 个原始场景。

求解后端：`python`。

优化目标：`cost`（最小化每轮候选方案补全全部任务后的 cost）。

距离：`visibility_dijkstra`（visibility_planner.VisibilityGraphPlanner: visibility graph + Dijkstra）；推理全程使用预计算距离表。

路径规划累计时间：180.512203 秒；规划阶段墙钟时间：24.512934 秒；缓存命中 0/100。

路径规划与缓存读写不计入推理时间；每个场景只预计算一次，供所有算法、参数组和重复运行复用。

CPU 工作进程数：8；每个进程逐场景求解。

时间为多个 CPU 进程并行运行时，单次完整求解的平均延迟，可能受资源竞争影响；不是整批耗时除以求解次数。

整批评估墙钟时间：448.372 秒；各次推理时间之和在并行时可大于整批墙钟时间。

算法细节、复现边界和 cost 补全规则见 [SOURCES.md](../../SOURCES.md)。
